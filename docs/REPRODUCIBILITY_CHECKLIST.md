# Reproducibility Checklist

- [x] Data sources identified with canonical citations.
- [x] Outcome variables identified by source.
- [x] ICU episode identifiers identified by source.
- [x] Missingness handling documented.
- [x] Model hyperparameters documented.
- [x] Software versions documented.
- [x] Fixed threshold documented as a reference threshold.
- [x] Bootstrap transfer uncertainty included.
- [x] Exact binomial intervals for sensitivity and specificity included.
- [x] Calibration summaries included.
- [x] Threshold sensitivity included.
- [x] Random-seed sensitivity included.
- [x] Class-weight sensitivity included.
- [x] Twenty-four-hour landmark sensitivity included.
- [x] Strict shared-feature sensitivity included.
- [x] Primary 24-hour shared-feature analysis included.
- [ ] Full patient-level data not redistributed publicly because source data are access-controlled.
- [ ] Full MIMIC/eICU replication should be run by authorized users before definitive deployment claims.
